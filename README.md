# 🍗 FoodDelivery YA

App de delivery autónoma (solo frontend) con IA, Maps y WhatsApp.

## Features
- 🗺️ Google Maps + geolocalización
- 🏪 Restaurantes cercanos por zona
- 🤖 Asistente Chef Bot
- 🎙️ Voz (entrada y salida)
- 🛒 Toma de pedidos
- 📱 WhatsApp integrado
